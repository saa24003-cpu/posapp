GitHub & Firebase Hosting デプロイ手順

1 GitHub リポジトリ (`posapp`) の作成とアップロード

PCの端末(Terminal / Command Prompt)で以下のコマンドを実行します。

# プロジェクトフォルダを作成して移動
mkdir posapp && cd posapp
# 本ファイルのコードを index.html として保存後、Git初期化
git init
git add index.html
git commit -m "Initial commit: POS App"
# GitHubで「posapp」リポジトリ作成後、作成したURLに紐付け
git branch -M main
git remote add origin https://github.com/あなたのユーザー名/posapp.git
git push -u origin main

2 Firebase Hosting へのデプロイ（Web公開）

CLIツールを使用してFirebaseに公開します。

# 1. Firebase CLI のインストール (未導入の場合)
npm install -g firebase-tools
# 2. Firebaseにログイン
firebase login
# 3. Hostingの初期化 (質問には public directory: . と答え、index.html の上書きは No)
firebase init hosting
# 4. デプロイ実行
firebase deploy
Firebase Auth のドメイン許可設定について

Firebase Consoleの「Authentication」→「設定」→「承認済みドメイン」に、Hostingで発行されたURL (例: your-app.web.app) を追加することで、本番URLからGoogleログインが可能になります。
